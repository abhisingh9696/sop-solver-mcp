Finance: `plan_pnl` (one set of numbers), `simulate` (template shocks, best/worst EBITDA). All engines stay deterministic and transparent; no ML forecasting, no vector DB, no MCP-side report generation. The `knowledge_hooks` prompt defines how to cite the S&OP book library into claims via `external_citations`.
